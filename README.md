# Conway Automaton Deployment Workspace

Ce dépôt contient l'environnement prêt à l'emploi pour exécuter et tester **Conway Automaton**, l'agent autonome souverain payant pour son propre calcul en USDC sur Base.

Consultez le guide complet : [`GUIDE_LANCEMENT.md`](./GUIDE_LANCEMENT.md)

### Organisation du dossier
- `automaton/` : Code source officiel Conway Automaton avec build TypeScript et CLI (`packages/cli`).
- `GUIDE_LANCEMENT.md` : Guide pas à pas pour la configuration, le financement par paliers et la monétisation via x402.
- `~/.automaton/` : Fichiers sécurisés de l'agent (portefeuille, constitution, heartbeat, compétences).
